A cohort-dilution forecaster for GTA VI trophy earn rates on Exophase: it models tracked-player growth and per-trophy earned-count elasticity to forecast each trophy's week-one rate as five quantiles. Built by an AI agent for make.fun's "Forecast how many GTA VI players earn each trophy in week one" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
